Markera flera saker – förslag

Skiss, inte spelet. Ett läge för att markera: knappen ☑ bredvid kugghjulet (eller Alt-klick → "Select items"). I läget markerar ett klick en sak i stället för att plocka upp den. Raden med pengar byts mot åtgärder för det markerade. Esc eller Done avslutar.
